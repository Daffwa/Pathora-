# Dokumentasi Praktik Git dan GitHub

Dokumen ini ditambahkan sebagai kontribusi kecil untuk memenuhi praktik kolaborasi Git dan GitHub pada proyek Pathora.

## Ringkasan Alur

1. Repository lokal diperiksa statusnya dengan `git status`.
2. Branch kontribusi dibuat dari `main`.
3. Perubahan dokumentasi ditambahkan dan di-commit.
4. Branch dikirim ke GitHub menggunakan `git push`.
5. Pull Request dibuat untuk proses review dan merge ke `main`.

## Catatan Kolaborasi

Perubahan ini sengaja dibatasi pada folder `docs/` agar aman untuk proyek utama dan mudah direview oleh anggota tim.
